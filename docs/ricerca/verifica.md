**Confutati / da correggere:**
- Versioni al 24 ago: il firmware più recente è **v4.36.0 (pubblicato 24 ago 2026)**, non 4.35.0; il qemu-pebble nel toolchain SDK 4.33.1 è **10.1.5-pebble14** (pebble17 esiste solo come release GitHub del 18 ago); il toolchain è xPack GNU Arm Embedded GCC 14.2.1 20241119 con newlib-nano; picolibc è la libc di default del *firmware* (commit 22 lug 2026), non dell'SDK app; "1.8.11-pebble1" non trovato.
- "CONFIG_MMAP_RESOURCES riduce la pressione RAM delle app": vale **solo per le risorse di sistema**; le risorse delle app terze vengono sempre copiate nell'heap app.
- "clock_to_timestamp() esplicitamente non DST-aware": nessuna nota DST nei doc e l'implementazione firmware **gestisce il DST** (time_get_isdst/dstoffset).
- "Installazione senza sudo": `pebble sdk install` scarica toolchain+qemu in user space, ma la pagina SDK ufficiale richiede `sudo apt install nodejs npm libsdl2-2.0-0 libglib2.0-0 libpixman-1-0 zlib1g libsndio7.0` (qemu-pebble fallisce senza libSDL2).

**Incerti:** "Bluetooth 5.3" per PT2 — nessuna fonte Core Devices lo dichiara (solo il product brief SiFli del SoC); l'assenza di Wi-Fi è coerente con SoC e pagina prodotto.
