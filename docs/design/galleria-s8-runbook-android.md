Vale con la specifica `galleria-s8-hardware.md` (obiettivi O1–O11, §3) e la tabella dei risultati `galleria-s8-risultati.md` (dove finiscono i numeri). ## 0. Prima di iniziare (una volta)

**L'utente**
1. Telefono: app **Pebble** (Core Devices) aggiornata dal Play Store (Impostazioni → App → Pebble → versione: da **1.8.0** va bene per la via A; per la via B (`--adb`) serve **≥ 1.10.0**; annotarla (sul Play Store oggi 1.11.0.3)). Orologio collegato e **aggiornato** al firmware che l'app propone.

3. Nell'app Pebble:
   - ⚙ **Settings → Connectivity → "Use LAN developer connection"** → ON (avviso "not secure": va bene sulla rete di casa).
   - Scheda dell'orologio → menu **⋯ → "Dev Connection"** → ON. Compare l'**indirizzo IP** del telefono: comunicarlo a Claude (es. `192.168.0.42`).
4. Scegliere **20 foto vere** nel telefono (miste: scure, chiare, cieli, volti, paesaggi con dettagli fini, ritratti in controluce). Le userà la config page.
5. Copiare sul telefono le **test card** (cartella `~/galleria-gate/cards/` di questa VM, 18 PNG generati da `python3 ../../tools/gen_test_cards.py --check`): via cavo dal PC Windows, via cloud/e‑mail, oppure con `adb push ~/galleria-gate/cards/ /sdcard/Download/GalleriaCards/` se si usa la via B. Nel selettore file della config page si trovano in *File → Download → GalleriaCards*. **Regola d'oro per le card** (altrimenti i numeri attesi non valgono): nella pagina lasciare **Luminosità (gamma)** a 1,00, **Schiarisci le ombre (lift)** a 0,00, **Dithering = «Nessuno»**, **«Ottimizza per il vetro» spento**; nell'editor premere solo **«Adatta»** (niente zoom o spostamenti: anche 1 px di ritaglio cambia i numeri; l'orientamento del telefono non conta), poi **«Aggiungi all'album»**. Sull'orologio: Text Size su **Default** (Settings → **Notifications** → Text Size) per `c8a`, `c8b`, `gray4` e `palette64`.
6. Facoltativo (solo per la via B, `--adb`): Impostazioni → Info sul telefono → toccare 7 volte "Numero build"; poi Sistema → Opzioni sviluppatore → **Debug wireless** ON.

**Claude (già fatto il 30/08)**: `tools/setup-adb.sh` (adb 37.0.1 in `~/.local`), le tre build in `apps/galleria/build_s8/` (`galleria_p.pbw` produzione 25.364/25.252 B, `galleria_m.pbw` misura, `galleria_417.pbw` D5 — tutte e tre già pronte, con gli ELF in `build_s8/<nome>/`), `galleria_logstats.py`, `gen_test_cards.py`.

## 2. Passi (Android + Pebble Time 2)

Note valide per tutti i passi:
- I comandi con log si lanciano come `timeout -s INT 600 pebble … --logs > run_s8_NN.log 2>&1` (o `pebble logs T`): finiscono da soli dopo 10 min oppure con Ctrl‑C; l'exit code 124 è normale.
- `pebble install --logs` aggancia i log **dopo** l'installazione: le prime righe (`heap main`, `JS_READY`) possono mancare. Rimedio: con `pebble logs T` attaccato, **riavviare la watchface** dall'orologio: **Select** (pulsante centrale a destra: apre l'elenco delle app) → **Watchfaces** → scegliere un'altra watchface → di nuovo **Select → Watchfaces → Galleria** → l'avvio si ripete e le righe compaiono. (Su/Giù da una watchface NON cambiano watchface: aprono la timeline.)
- Nei comandi `pebble install` il nome del `.pbw` viene **prima** delle opzioni (`pebble install build_s8/… T --logs`): con `--adb` un percorso subito dopo il flag verrebbe letto come seriale del dispositivo.
- Prima di installare una build diversa dalla P, Claude copia il suo ELF in `build/<piatt>/pebble-app.elf` (serve alla desimbolizzazione automatica dei crash) e ripristina quello della P al ritorno.
- L'app Pebble **perde** i log JavaScript quando arrivano a raffica (buffer da 2 righe): le righe `[sync] chunk … ack` non sono affidabili; contano quelle dell'orologio (`sync: end`, `sync: gap`).
- **Mentre la pagina delle impostazioni è aperta non toccare l'orologio**: se Galleria viene chiusa o riavviata sull'orologio (pulsanti, un'altra watchface, un'installazione), l'app chiude la pagina e quello che avevi preparato va perso.
- Screenshot dell'orologio: `pebble screenshot T --no-open shot_s8_NN.png` (via BLE: 10–30 s; con `--no-correction` i colori nominali).

## 3. Pebble 2 Duo (flint)

Stessi §0–§1 (l'app gestisce più orologi: selezionare il Duo). Le card flint sono in `~/galleria-gate/cards/` con prefisso `f`: sono immagini 200×228 a strisce verticali a tutta altezza (la pagina ne prende la parte centrale 195×228 e la riduce a 144×168; `f4_40w` è in realtà al 41,7 % di bianco e `f5_60w` al 61,1 %: attesi `f1` bianco, `f2` nero, `f3` nero (pareggio → media 127), `f4` bianco, `f5` nero, alone sempre acceso su flint). Stessa regola d'oro del §0.5 (dithering «Nessuno» = 1 bit senza dithering).

## 5. Glossario delle righe di log più importanti

| Riga | Significato |
|---|---|
| `heap main: used= free=` | avvio dell'app (uno per esecuzione; due senza `heap deinit` in mezzo = riavvio spontaneo) |
| `watch: fw 4.36.2 model=N` | firmware e modello (10 = Pebble 2 Duo, 11 = Pebble Time 2, 12 = Pebble Round 2) |
| `batt: 87% chg=0 plug=0 up 123 min` | batteria e minuti dall'avvio (a ogni gradino del 10 %) |
| `storage: quota=… album=1 … valid=k` | quota persist reale, album abilitato, k foto valide |
| `sync: end s=slot c=0 n=9 commit C photo P ch max M avg A heap H` | foto ricevuta: P ms totali, per messaggio max M / media A ms (16 scritture persist da 256 B) |
| `sync: gap n=8 max M avg A` (build M) | ms fra un chunk e il successivo = BLE + telefono **+ le 16 scritture persist del chunk precedente** (sottrarre `ch avg` per la sola parte radio; `n/d (salto orologio)` nel riepilogo = valore falsato dalla risincronizzazione) |
| `photo: slot k persist crc ok 134 ch N ms` | foto riletta da persist in N ms |
| `luma(photo): … bad=w(bw/bb) mean=m fg=ff\|c0 halo=0\|1` | decisione del colore: bianco (`fg=ff`) o nero (`fg=c0`; `w=1|0` lo dice in chiaro), alone sì/no |
| `draw: mode=1 full=0 N ms info M` (build M) | render della fascia in N ms, di cui M per la riga info |
| `bt: connected=0\|1` | telefono scollegato/collegato |
| `[config] pagina chiusa: risposta di N car. dopo T ms` | tempo passato nella pagina e dimensione del payload |
| `[config] payload applicato in T ms` | scrittura dell'album nel telefono |
| `rot(tick\|shake\|init): … slot=k` | cambio foto (a orologio, a scossa, all'avvio); k = posto nell'album |
| `sync: 30 s idle -> IDLE` | la sync si è fermata da sola (telefono lontano/app chiusa): riprende col retry |
